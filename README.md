## Structure of the Field Manual

1. **Razors** — Heuristics for cutting noise (Occam, Hanlon, Chesterton, etc.)
2. **Cognitive Biases** — 30 mental traps with mitigations
3. **Mental Models** — 21 portable tools for thinking (first principles, feedback loops, optionality, etc.)
4. **Game Theory** — Strategic interaction, classic games, and applications
5. **History & Cycles** — Turning points, recurring failure modes, and empire patterns
6. **Operational Guides** — Decision review template, pre-mortems, crisis drills
7. **Further Study** — Annotated bibliography with links to detailed book references
8. **Quick Reference Checklists** — Printer-friendly summary checklists

## How to Use

- Start with the **Quick Reference Checklists** (Section 8) for fast recall.
- Dive into specific sections when facing a decision, diagnosis, or strategy question.
- Use the **book_references/** folder for deeper study on any topic.
- Check **failures.md** to understand when a tool is the wrong choice.
